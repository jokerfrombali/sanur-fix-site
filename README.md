# Sanur Fix — сайт мастера (сантехника, бассейны, мелкий ремонт), только Санур

- `site/` — готовый статический сайт (RU в корне, EN в `/en/`), 34 страницы.
- `build_site.py` — генератор. Контакты, цены, домен, ссылка на Google-карточку — в начале файла. Пересборка: `python build_site.py`.
- SEO-ядро — в приватном репозитории `sanur-fix-seo`.

Перед публикацией заменить заглушки: `WHATSAPP`, `PHONE`, `TELEGRAM`, `DOMAIN`, фото мастера.
Фото — Unsplash (бесплатная лицензия), авторы в подвале сайта.
